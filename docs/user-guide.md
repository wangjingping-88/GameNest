# GameNest 0.2.3 用户说明

GameNest 是本地优先的 Windows 单机游戏启动器。游戏库、封面、扫描结果、游玩记录和设置都保存在本机，不需要账号或在线服务。

## 系统要求

- Windows 10 2004（内部版本 19041）或更高版本，推荐 Windows 11；
- x64 处理器；
- 普通用户权限即可使用。FPS 采集在部分电脑上需要管理员把当前账号加入 `Performance Log Users`，GameNest 不会自动提权或修改用户组。

便携版已经包含 .NET 10、Windows App SDK 2.3.1、覆盖层程序和经过哈希校验的 PresentMon 2.5.1，不需要另行安装运行时。

## 安装与启动

1. 校验下载页提供的 SHA-256。
2. 把 ZIP 完整解压到一个可写目录，不要直接在压缩包内运行。
3. 双击 `GameNest.App.exe`。
4. Windows 首次提示时确认文件来自可信发布来源；0.2.3 便携版暂未进行 Authenticode 代码签名。

首次启动会在 `%LOCALAPPDATA%\GameNest` 创建数据库、图片缓存、日志和备份目录。移动或删除便携版程序目录不会自动删除这些数据。

主窗口默认及最小尺寸为 `1680×1000`。最大化后页面内容仍保持左侧和顶部基线，不会随窗口等比放大；在高 DPI 或系统工作区被强制压缩时，设置详情区域会提供局部滚动。

## 设置分类与外观

设置页左侧提供“性能覆盖层、应用外观、应用更新、数据与维护、兼容性检测”五个分类，右侧一次只显示当前分类。重新进入设置页时，会保留本次运行中最后选择的分类。

- “应用外观”中的浅色、深色和跟随系统采用纵向排列，可用键盘在分类和选项之间移动；
- 浅色主题使用原始横向 Logo，深色主题自动切换为透明底冷灰字标，跟随系统会随 Windows 当前应用模式即时更新；
- 超长更新发布说明只在说明区域内部滚动，不会拉高整个设置页。

## 添加与扫描游戏

- 单个添加：在首页或游戏库选择“添加游戏”，选择 `.exe` 或 `.lnk`。
- 目录扫描：打开“扫描与导入”，先添加明确的游戏目录，再运行快速或深度扫描。GameNest 不会默认遍历系统盘。
- 候选确认：查看候选分数和命中依据，勾选后再加入游戏库。扫描结果不会自动启动程序。
- 封面：在游戏详情选择本地图片。GameNest 只保存受控尺寸的本地缩略图，不移动或删除原图。

## 启动、会话与覆盖层

- 从详情启动游戏后，GameNest 会识别已确认的实际游戏进程并记录本次会话。
- 停止操作先请求正常关闭；只有仍在运行且身份已确认时，才显示带存档风险的强制结束确认。
- 覆盖层适合窗口化和无边框全屏。传统独占全屏、反作弊保护或 ETW 权限限制可能使个别指标显示 `--`。
- 详细边界见 `OVERLAY-COMPATIBILITY.md`。

## 备份、缓存与诊断

在“设置 → 数据与维护”中：

- GameNest 每次启动都会检查自动备份；24 小时内最多创建一次，自动保留最近 7 份；
- “立即备份”会额外创建一份不会被自动轮换删除的手工备份；
- “清理缓存”只删除数据库没有引用的 GameNest 图片缓存，不触碰原始游戏和原始封面；
- “导出诊断信息”只在用户选择的目录生成 ZIP，包含版本、系统概况、数据数量统计和最近 3 份脱敏日志，不包含数据库、游戏标题、游戏路径或凭据。

本地数据目录：`%LOCALAPPDATA%\GameNest`

- `data\gamenest.db`：游戏库与设置；
- `assets\cache`：图标和封面缩略图；
- `backups`：自动及手工数据库备份；
- `logs`：本地滚动日志。

## 应用更新

在“设置 → 应用更新”中可查看当前版本、手动检查或关闭自动检查。自动检查每 24 小时最多向公开 GitHub 仓库发送一次标准 HTTPS 请求，只检查 GameNest 本身，不检查或更新游戏。

- 只有最新正式 Release 会显示；草稿和预发布版本被忽略。
- 发现更新后会在全局区域显示非打扰提示，并展示版本、发布时间和纯文本发布说明。
- 配置受信生产公钥的便携版可以在用户点击确认后下载、验签、校验 SHA-256 并安装；更新前自动创建数据库备份。
- 普通权限无法写入当前目录、目录没有 `.gamenest-portable-root` 或当前版本未内置生产公钥时，不会提权，会打开 GitHub 下载页供手动处理。
- 升级只等待 GameNest 主程序和覆盖层正常退出，不强制结束游戏。新版初始化失败时会恢复旧程序目录和更新前数据库备份。
- 0.1.0 不包含更新客户端，历史 `v0.2.0`、`v0.2.1` 和 `v0.2.2` 未形成 Release，均须手动安装 0.2.3；第一个在线升级验证路径是 0.2.3 到 0.2.4。

独立更新签名用于验证发布资产，但不能消除未做 Authenticode 签名带来的 SmartScreen 提示。

## 卸载

1. 关闭 GameNest。
2. 在便携版目录运行 `Uninstall-GameNest.cmd`。
3. 卸载脚本会明确询问：
   - 保留数据库、备份、日志和封面缓存（默认）；或
   - 删除全部 GameNest 本地数据。
4. 确认后脚本删除便携版程序目录。若选择保留，以后重新解压同版本或新版本即可继续使用原数据库和缓存。

如果脚本被安全策略阻止，可保留 `%LOCALAPPDATA%\GameNest` 后手工删除便携版目录；需要彻底移除时，再手工删除该本地数据目录。
