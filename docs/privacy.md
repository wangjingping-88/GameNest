# GameNest 本地数据与隐私说明

GameNest 是本地优先工具。性能指标只在本机、只针对当前已确认的游戏进程组采集；Phase 6 的维护操作也只访问 GameNest 自己的数据目录和用户明确选择的导出目录。

- 不上传 FPS、CPU、GPU、RAM、游戏路径、游戏列表或游玩记录；
- 不创建账号，不要求 API Key，不包含在线遥测 SDK；
- PresentMon 输出只在内存中解析，不保留永久 CSV；
- CPU 和 RAM 来自已确认进程组，GPU 来自 Windows GPU Engine 性能计数器；
- 覆盖层只通过当前用户命名管道接收有限长度、带版本的结构化状态，不接受任意命令；
- 覆盖层关闭或游戏退出后停止 FPS/PDH 会话并释放窗口句柄；
- 日志只用于本地诊断，不应记录认证信息或用户敏感环境变量。
- Phase 5 默认不注册在线元数据提供者，不发送搜索词、游戏路径或游戏列表；
- 用户选择的封面只在本机生成受控尺寸缩略图，原始图片不会被上传、移动或删除；
- 图标和封面缩略图按内容哈希保存在 `%LOCALAPPDATA%\GameNest\assets\cache`。
- 启动后每天最多自动创建一份 SQLite 一致性备份，默认只保留最近 7 份自动备份；手工备份不会被自动轮换删除；
- 缓存清理只删除数据库不再引用的 GameNest 图片缓存，不读取或删除原始游戏和原始封面；
- 诊断导出必须由用户主动触发并选择保存目录，只包含版本、系统概况、数量/容量统计和最近 3 份脱敏日志；
- 诊断包不包含数据库、游戏标题、游戏路径、封面原图、API Key、令牌或其他凭据。

本地持久化位置仍为 `%LOCALAPPDATA%\GameNest`。便携版卸载脚本默认保留该目录，并在删除程序前明确询问是否同时删除数据库、备份、图标/封面缓存和日志。
