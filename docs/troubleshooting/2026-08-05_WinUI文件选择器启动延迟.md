# WinUI 3 桌面应用文件选择器启动延迟

## 现象

未打包 WinUI 3 应用使用 `Windows.Storage.Pickers.FileOpenPicker` 或 `FolderPicker`，再通过 `InitializeWithWindow` 绑定 HWND 时，点击按钮后文件管理器弹窗可能延迟约 2 秒出现。

## 原因与处理

旧 API 走兼容的桌面代理路径。Windows App SDK 2.3 已提供 `Microsoft.Windows.Storage.Pickers`：构造选择器时直接传入 `AppWindow.Id`，不再调用 `InitializeWithWindow`。

同时设置稳定的 `SettingsIdentifier`，让系统记住两个入口各自的最近位置，并用 `_isPickerOpen` 阻止等待期间重复打开多个选择器。

> [!tip]
> 需要区分“弹窗出现慢”和“选择文件后导入慢”。前者测量从 Click 到选择器窗口出现；后者分别测量文件检查、SQLite 写入和后台图标提取。

## 性能测试注意

冷添加预算测试在四个测试程序集并行运行、机器有明显争用时曾测得 2310 ms；同一测试单独运行是 280 ms，全量复跑也通过。性能断言失败时应先保留失败证据，再用单测隔离判断是产品回归还是测试机争用，不能直接删除或放宽预算。
